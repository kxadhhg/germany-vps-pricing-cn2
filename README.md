## 线路：CN2 GIA 加持下，德国机房能压到多少延迟

法兰克福到国内的物理距离摆在那儿，光速跑一趟就要一百多毫秒，所以德国线路比的不是绝对值，是有没有走优化路由。AkkoCloud 这条线去程分运营商走：电信走 CN2 GIA 到伦敦后转法兰克福，联通走 AS4837 直连，移动走 CMI 直连；回程电信、联通走 CN2 GIA，移动走 CMIN2。

CN2 GIA 是中国电信的精品国际专线，走 59.43 节点直连，路由短、丢包少，晚高峰不容易被普通国际出口的拥堵拖住。

第三方测评给出的数字是：国内多地平均 ping 在 177ms 上下，电信、联通大致 170ms 出头，移动稍高一点；另一篇写的是 150–180ms 区间。两组数据能互相印证，但都是测评者自测，不是你所在城市的必然结果。作为参照，走普通国际线路的德国 VPS 晚高峰经常在 230ms 以上，差的时候三四百毫秒也见过。

想自己验，官方给了测试入口：测试 IP **185.217.109.94**，测速文件 http://fralg.akkocloud.com/。**晚 8 点到 11 点跑一遍 ping 和路由**，这个时段的数字才有参考价值，白天测出来的低延迟说明不了问题。

延迟在 170ms 上下意味着什么：SSH 敲命令不会顿，跨境店铺后台点按钮基本跟手，远程桌面能用但拖窗口会有拖影。要拿来打游戏或者实时音视频，欧洲节点本身就别指望。
